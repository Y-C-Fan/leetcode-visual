爬楼梯：动态规划可视化

LeetCode 70 | 示例：n = 5

Step 0 n: -
当前计算 dp[n] 来源 dp[n-1] 来源 dp[n-2]
dp[n] = dp[n-1] + dp[n-2]

操作日志

递推公式：dp[n] = dp[n-1] + dp[n-2]

问题理解

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。
每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶？

递推公式推导

设 dp[n] 表示爬到第 n 阶楼梯的方法数。
要到达第 n 阶，只能从以下两个位置过来：

1. 从第 n-1 阶爬 1 步上来（有 dp[n-1] 种方法）
2. 从第 n-2 阶爬 2 步上来（有 dp[n-2] 种方法）
因此：dp[n] = dp[n-1] + dp[n-2]

初始化

dp[0] = 1（站在地面，视为 1 种方法）
dp[1] = 1（爬 1 阶，只有 1 种方法：爬 1 步）

Java 代码实现（代码随想录）

public int climbStairs(int n) { if (n <= 1) return n; int[] dp = new int[n + 1]; dp[0] = 1; // 初始化 dp[1] = 1; // 初始化 for (int i = 2; i <= n; i++) { dp[i] = dp[i - 1] + dp[i - 2]; // 递推公式 } return dp[n]; }

本例结果

n = 5 时，共有 8 种方法：
1+1+1+1+1, 2+1+1+1, 1+2+1+1, 1+1+2+1, 1+1+1+2, 2+2+1, 2+1+2, 1+2+2
