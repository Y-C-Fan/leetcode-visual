操作日志

需要同时维护最大值和最小值，因为负数可能使最小值变为最大值

问题定义

给定一个整数数组 nums，找出数组中乘积最大的非空连续子数组，并返回该子数组对应的乘积。

为什么需要同时维护最大值和最小值？

由于数组中可能包含负数，负数乘以负数会变成正数。 因此，当我们遇到一个负数时，之前的最小值（负数）乘以这个负数可能会变成新的最大值。

动态规划思路

使用两个 DP 数组： - maxDP[i]：以 nums[i] 结尾的子数组的最大乘积 - minDP[i]：以 nums[i] 结尾的子数组的最小乘积

递推公式

maxDP[i] = max(nums[i], maxDP[i-1] * nums[i], minDP[i-1] * nums[i])
minDP[i] = min(nums[i], maxDP[i-1] * nums[i], minDP[i-1] * nums[i])

对于每个位置 i，我们有三种选择： 1. nums[i]：从当前元素重新开始 2. maxDP[i-1] * nums[i]：延续之前的最大乘积 3. minDP[i-1] * nums[i]：延续之前的最小乘积（可能是负数）

初始化

maxDP[0] = minDP[0] = nums[0]
globalMax = nums[0]

Java 代码实现

public int maxProduct(int[] nums) {
    int n = nums.length;
    int[] maxDP = new int[n];
    int[] minDP = new int[n];
    
    // 初始化
    maxDP[0] = minDP[0] = nums[0];
    int globalMax = nums[0];
    
    for (int i = 1; i < n; i++) {
        // 递推公式：同时更新最大值和最小值
        maxDP[i] = Math.max(nums[i], 
            Math.max(maxDP[i - 1] * nums[i], minDP[i - 1] * nums[i]));
        minDP[i] = Math.min(nums[i], 
            Math.min(maxDP[i - 1] * nums[i], minDP[i - 1] * nums[i]));
        
        // 更新全局最大值
        globalMax = Math.max(globalMax, maxDP[i]);
    }
    return globalMax;
}
