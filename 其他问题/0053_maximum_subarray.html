公式：dp[i] = max(nums[i], dp[i-1] + nums[i])

问题定义

给定一个整数数组 nums，找到一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

动态规划思路

设 dp[i] 表示以 nums[i] 结尾的连续子数组的最大和。

递推公式

对于每个位置 i，我们有两种选择：

dp[i] = max(nums[i], dp[i-1] + nums[i])

其中： - nums[i]：从当前位置重新开始一个新的子数组 - dp[i-1] + nums[i]：延续之前的子数组，加上当前元素

初始化

dp[0] = nums[0]
globalMax = nums[0]

Java 代码实现

public int maxSubArray(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];  // 初始化
    int globalMax = nums[0];
    
    for (int i = 1; i < n; i++) {
        // 递推公式：选择重新开始或延续
        dp[i] = Math.max(nums[i], dp[i - 1] + nums[i]);
        
        // 更新全局最大值
        globalMax = Math.max(globalMax, dp[i]);
    }
    return globalMax;
}
