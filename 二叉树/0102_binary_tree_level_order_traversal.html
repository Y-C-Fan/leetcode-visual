🧠 为什么第 8 行要写 int size = q.size()？

如果直接写 while(!q.isEmpty()) 控制内层循环，那么第 12、13 行刚入队的孩子会被当成同一层处理， 就退化成了"把整棵树按 DFS 顺序拍平"，分层信息全丢。
先把进入本层时队列的长度拍成快照 size，再用 for(i=0;i<size;i++) 只取这么多元素—— 新入队的节点排在队尾，本轮不会被碰到，它们属于下一层。
这就是"分层"这件事在代码里唯一的实现方式。
