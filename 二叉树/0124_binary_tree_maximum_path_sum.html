④ 为什么这样写（两个关键决策）

决策 A：ans 更新用 left + right（两边都要）
路径经过当前节点时，父节点只需要 一条 链往下走，但当前节点自己可以同时接住左子树最优链和右子树最优链，拼成一条完整路径。 所以 ans = max(ans, val + left + right)，这里就是路径的“拐点”或“山顶”。
整棵树里被这样更新到最大值的那个节点，就是答案路径的拐点。
决策 B：返回值只取一边 val + max(left, right)
向上返回的语义是：“以我为端点、向下延伸的最长链”。一条链只有一个方向能继续，所以只能二选一。 若把两边都返回上去，返回的就不再是“链”而是“分叉的树”，父节点拼出来的路径会重复经过子树，答案会错。
为什么要 Math.max(0, dfs(...))
子树返回的负数代表“从我往那边走会拖低总和”。路径可以不往那边拐，所以直接归零。 好处是全树 val + max(left,right) 天然非负，只有根节点可能为负——这也解释了为什么 ans 必须初始化成 Integer.MIN_VALUE 而不能是 0 （否则 [-3] 会答 0）。
整体形状
一次后序遍历 + 一个全局变量，O(n) 时间、O(h) 递归栈。 每个节点做两件互不冲突的事：向上贡献一条链，同时把自己拼成一条完整路径参与 ans 竞争。
