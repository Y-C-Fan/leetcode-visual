class Solution {
List<List<Integer>> res = new ArrayList<>();
List<Integer> path = new ArrayList<>();
boolean[] used;
public List<List<Integer>> permute(int[] nums) {
used = new boolean[nums.length];
dfs(nums);
return res;
}
public void dfs(int[] nums){
if(path.size() == nums.length){
res.add(new ArrayList<>(path));
return;
}
for(int i = 0; i < nums.length; i++){
if(used[i]) continue;
path.add(nums[i]);
used[i] = true;
dfs(nums);
path.remove(path.size() - 1);
used[i] = false;
}
}
}

回溯五句话

  1. path：已选的前缀，第 depth 位正在填谁。
  2. used[i]：nums[i] 是否已在 path 里，保证每个数字只用一次。
  3. 终止：path.size() == n 就收集，注意必须 new ArrayList<>(path) 拷贝，否则后面 remove 会改掉已收集的结果。
  4. 试探：for 循环把每个未使用的 i 轮流放到末尾，递归下去。
  5. 撤销：递归返回后 remove + used=false，把位置让出来给下一个 i。

看动画时盯什么

  • 搜索树自上而下逐个点亮：紫色描边 = 当前 dfs 节点，黄边 = 来时的路径，绿色 = 已收集的叶子。
  • 右侧代码随步骤高亮：if 判满 / continue 跳过 / add 做选择 / remove 撤销，当前 i 显示在代码上方。
  • 每次 backtrack 之后，树上回到父节点、path 缩短一格、used 恢复 false —— 这就是"回溯"。

复杂度

  • 时间：共 n! 种排列，每种长 n → O(n · n!)。
  • 空间：递归深度 n + used 数组 n → O(n)（不计 res）。
for 循环按 i = 0 → n-1 依次试探：used 跳过 → 选入 path → 递归 → 撤销（remove + used=false）。
