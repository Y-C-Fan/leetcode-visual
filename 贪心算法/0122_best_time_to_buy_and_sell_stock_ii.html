问题定义

给定一个数组 prices，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。 你可以完成任意次数的交易（即买入和卖出一只股票），设计一个算法来计算你所能获取的最大利润。 注意：你不能同时参与多笔交易（你必须在再次买入前卖出掉之前的股票）。

动态规划思路

由于可以多次交易，我们可以收集所有上涨的利润。 只要今天的价格比昨天高，就进行交易（昨天买入，今天卖出）。

递推公式

对于每一天 i（从第 2 天开始）：

if prices[i] > prices[i-1]:
  profit += prices[i] - prices[i-1]

其中： - profit：累计的总利润 - prices[i] - prices[i-1]：相邻两天的价格差（如果为正则加入利润）

初始化

profit = 0

Java 代码实现

public int maxProfit(int[] prices) {
    int profit = 0;  // 初始化总利润
    
    for (int i = 1; i < prices.length; i++) {
        // 如果今天价格比昨天高，进行交易
        if (prices[i] > prices[i - 1]) {
            profit += prices[i] - prices[i - 1];  // 递推公式
        }
    }
    return profit;
}
