问题定义

给定一个字符串 s，找到 s 中最长的回文子串。回文串是指正着读和反着读都一样的字符串。

动态规划思路

设 dp[left][right] 表示 s[left...right] 是否为回文串。 我们需要找到所有可能的子串，判断它们是否为回文串，并记录最长的。

递推公式

对于子串 s[left...right]：

dp[left][right] = (s[left] == s[right]) && dp[left+1][right-1]

边界条件： - dp[i][i] = true：单个字符是回文串 - dp[i][i+1] = (s[i] == s[i+1])：两个字符相邻且相同是回文串

遍历顺序

外层循环遍历子串长度 len（从 2 到 n），内层循环遍历左边界 left（从 0 到 n-len）。 这样可以确保在计算 dp[left][right] 时，dp[left+1][right-1] 已经被计算过。

Java 代码实现

public String longestPalindrome(String s) {
    int n = s.length();
    boolean[][] dp = new boolean[n][n];
    int start = 0, maxLen = 1;
    
    // 初始化：单个字符是回文串
    for (int i = 0; i < n; i++) dp[i][i] = true;
    
    // 按子串长度遍历
    for (int len = 2; len <= n; len++) {
        for (int left = 0; left <= n - len; left++) {
            int right = left + len - 1;
            
            // 递推公式
            if (s.charAt(left) == s.charAt(right)) {
                boolean innerPalin = (len == 2) || dp[left + 1][right - 1];
                dp[left][right] = innerPalin;
                
                // 更新最长回文子串
                if (innerPalin && len > maxLen) {
                    start = left;
                    maxLen = len;
                }
            }
        }
    }
    return s.substring(start, start + maxLen);
}
