问题定义

给定三个字符串 s1、s2 和 s3，判断 s3 是否由 s1 和 s2 交错组成。 交错组成的定义是：s3 中的字符由 s1 和 s2 的字符按顺序交替组成。

动态规划思路

设 dp[i][j] 表示 s1 的前 i 个字符和 s2 的前 j 个字符能否交错组成 s3 的前 i+j 个字符。

递推公式

对于 dp[i][j]：

dp[i][j] = (s1[i-1] == s3[i+j-1] && dp[i-1][j]) || (s2[j-1] == s3[i+j-1] && dp[i][j-1])

边界条件： - dp[0][0] = true：空字符串可以组成空字符串 - dp[0][j] = dp[0][j-1] && s2[j-1] == s3[j-1] - dp[i][0] = dp[i-1][0] && s1[i-1] == s3[i-1]

Java 代码实现

public boolean isInterleave(String s1, String s2, String s3) {
    int m = s1.length(), n = s2.length();
    if (m + n != s3.length()) return false;
    
    boolean[][] dp = new boolean[m + 1][n + 1];
    dp[0][0] = true;  // 初始化
    
    // 初始化第一行和第一列
    for (int i = 1; i <= m; i++) {
        dp[i][0] = dp[i - 1][0] && s1.charAt(i - 1) == s3.charAt(i - 1);
    }
    for (int j = 1; j <= n; j++) {
        dp[0][j] = dp[0][j - 1] && s2.charAt(j - 1) == s3.charAt(j - 1);
    }
    
    // 填充 DP 表格
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            boolean fromS1 = s1.charAt(i - 1) == s3.charAt(i + j - 1) && dp[i - 1][j];
            boolean fromS2 = s2.charAt(j - 1) == s3.charAt(i + j - 1) && dp[i][j - 1];
            dp[i][j] = fromS1 || fromS2;  // 递推公式
        }
    }
    return dp[m][n];
}
