操作日志

递推公式：dp[i][j] = dp[i-1][j-1] + 1 if text1[i-1]==text2[j-1] else max(dp[i-1][j], dp[i][j-1])

问题理解

给定两个字符串 text1 和 text2，返回这两个字符串的最长公共子序列的长度。
如果不存在公共子序列，返回 0。
一个字符串的子序列是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。

递推公式推导

设 dp[i][j] 表示 text1[0...i-1] 和 text2[0...j-1] 的最长公共子序列长度。
对于每个位置 (i, j)，有两种情况：

1. 字符匹配：如果 text1[i-1] == text2[j-1]
那么这个字符可以加入公共子序列，dp[i][j] = dp[i-1][j-1] + 1
2. 字符不匹配：如果 text1[i-1] != text2[j-1]
那么至少有一个字符不能加入，dp[i][j] = max(dp[i-1][j], dp[i][j-1])

初始化

dp[0][j] = 0（空字符串与任何字符串的最长公共子序列长度为 0）
dp[i][0] = 0（空字符串与任何字符串的最长公共子序列长度为 0）

Java 代码实现（代码随想录）

public int longestCommonSubsequence(String text1, String text2) { int m = text1.length(); int n = text2.length(); int[][] dp = new int[m + 1][n + 1]; for (int i = 1; i <= m; i++) { for (int j = 1; j <= n; j++) { if (text1.charAt(i - 1) == text2.charAt(j - 1)) { dp[i][j] = dp[i - 1][j - 1] + 1; // 字符匹配 } else { dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]); // 字符不匹配 } } } return dp[m][n]; }

本例结果

text1 = "abcde", text2 = "ace"
最长公共子序列为 "ace"，长度为 3
