公式：dp[i][j] = dp[i-1][j] + dp[i][j-1]

问题定义

一个机器人位于一个 m x n 网格的左上角，机器人每次只能向下或者向右移动一步。 机器人试图达到网格的右下角，问总共有多少条不同的路径？

动态规划思路

设 dp[i][j] 表示从左上角 (0, 0) 到达位置 (i, j) 的不同路径数。

递推公式

对于每个位置 (i, j)，可以从上方 (i-1, j) 或左方 (i, j-1) 到达：

dp[i][j] = dp[i-1][j] + dp[i][j-1]

边界条件： - dp[0][j] = 1：第一行，只能从左方到达，只有一条路径 - dp[i][0] = 1：第一列，只能从上方到达，只有一条路径

Java 代码实现

public int uniquePaths(int m, int n) {
    int[][] dp = new int[m][n];
    
    // 初始化第一行和第一列
    for (int i = 0; i < m; i++) dp[i][0] = 1;
    for (int j = 0; j < n; j++) dp[0][j] = 1;
    
    // 填充其余位置
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1];  // 递推公式
        }
    }
    return dp[m - 1][n - 1];
}

本例分析

m = 3, n = 7
最终结果：28
这是一个组合问题，从 (0,0) 到 (m-1,n-1) 需要移动 m-1 次向下和 n-1 次向右，总共 m+n-2 步。
不同路径数 = C(m+n-2, m-1) = C(8, 2) = 28
