问题定义

给定一个三角形 triangle，找出自顶向下的最小路径和。每一步只能移动到下一行中相邻的结点上。 相邻的结点指的是下标与上一层结点下标相同或等于上一层结点下标 + 1 的两个结点。

动态规划思路

设 dp[i][j] 表示从三角形顶部到达位置 (i, j) 的最小路径和。

递推公式

对于每个位置 (i, j)，可以从上一行的 (i-1, j-1) 或 (i-1, j) 到达：

dp[i][j] = triangle[i][j] + min(dp[i-1][j-1], dp[i-1][j])

边界条件： - dp[i][0] = triangle[i][0] + dp[i-1][0]（最左侧，只能从上方到达） - dp[i][i] = triangle[i][i] + dp[i-1][i-1]（最右侧，只能从左上方到达）

初始化

dp[0][0] = triangle[0][0]：顶点的路径和就是它本身

Java 代码实现

public int minimumTotal(List<List<Integer>> triangle) {
    int n = triangle.size();
    int[][] dp = new int[n][n];
    dp[0][0] = triangle.get(0).get(0);  // 初始化
    
    for (int i = 1; i < n; i++) {
        // 最左侧元素
        dp[i][0] = triangle.get(i).get(0) + dp[i - 1][0];
        
        // 中间元素
        for (int j = 1; j < i; j++) {
            dp[i][j] = triangle.get(i).get(j) + 
                Math.min(dp[i - 1][j - 1], dp[i - 1][j]);  // 递推公式
        }
        
        // 最右侧元素
        dp[i][i] = triangle.get(i).get(i) + dp[i - 1][i - 1];
    }
    
    // 返回最后一行的最小值
    int minSum = dp[n - 1][0];
    for (int j = 1; j < n; j++) {
        minSum = Math.min(minSum, dp[n - 1][j]);
    }
    return minSum;
}
