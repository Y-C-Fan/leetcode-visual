问题定义

给定一个只包含 '(' 和 ')' 的字符串，找出最长的有效（正确闭合）括号子串的长度。

动态规划思路

设 dp[i] 表示以 s[i] 结尾的最长有效括号子串的长度。 我们需要考虑 s[i] 是 '(' 还是 ')' 的情况。

递推公式

对于每个位置 i：

if s[i] == '(':
  dp[i] = 0 (以 '(' 结尾无法形成有效括号)
else if s[i] == ')':
  if s[i-1] == '(':
    dp[i] = (i >= 2 ? dp[i-2] : 0) + 2
  else if s[i-1] == ')' and s[i-dp[i-1]-1] == '(':
    dp[i] = dp[i-1] + 2 + (i-dp[i-1] >= 2 ? dp[i-dp[i-1]-2] : 0)

初始化

dp[0] = 0（单个字符无法形成有效括号）

Java 代码实现

public int longestValidParentheses(String s) {
    int n = s.length();
    int[] dp = new int[n];
    int maxLen = 0;
    
    for (int i = 1; i < n; i++) {
        if (s.charAt(i) == ')') {
            if (s.charAt(i - 1) == '(') {
                // 情况1：(...)
                dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
            } else if (i - dp[i - 1] - 1 >= 0 && s.charAt(i - dp[i - 1] - 1) == '(') {
                // 情况2：...(...)
                dp[i] = dp[i - 1] + 2 + (i - dp[i - 1] - 2 >= 0 ? dp[i - dp[i - 1] - 2] : 0);
            }
            maxLen = Math.max(maxLen, dp[i]);  // 更新最大长度
        }
    }
    return maxLen;
}
