问题定义

给定一个只包含正整数的非空数组 nums，判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

问题转化

如果数组能被分割成两个等和子集，那么每个子集的和应该是 totalSum / 2。 因此，问题转化为：能否从数组中选取若干数，使其和等于 target = totalSum / 2。

动态规划思路

这是一个 0/1 背包问题。设 dp[i][j] 表示前 i 个物品，容量为 j 时的最大价值（这里价值和重量相等，都是 nums[i]）。

递推公式

dp[i][j] = max(dp[i-1][j], dp[i-1][j-nums[i]] + nums[i])

其中： - dp[i-1][j]：不选第 i 个物品，保持上一行的状态 - dp[i-1][j-nums[i]] + nums[i]：选第 i 个物品，腾出空间后 + 当前物品价值

初始化

dp[0][j] = nums[0]（当 j >= nums[0]）：第一个物品初始化
dp[0][j] = 0（当 j < nums[0]）：容量不够

Java 代码实现

  public boolean canPartition(int[] nums) {
      int len = nums.length;
      int sum = 0;
      for (int num : nums) sum += num;
      
      if (sum % 2 != 0) return false;
      
      int target = sum / 2;
      
      // 【步骤 1】定义 DP 数组
      // dp[i][j]: 前 i 个物品，容量为 j 时的最大价值
      int[][] dp = new int[len][target + 1];
      
      // 【步骤 2】初始化第 0 行 (手动处理第一个物品)
      // 这一步必须做，否则后面 i 从 1 开始没法算
      for (int j = nums[0]; j <= target; j++) {
          dp[0][j] = nums[0];
      }
      
      // 【步骤 3】双层循环 (标准的 0-1 背包逻辑)
      // i 从 1 开始，因为 0 已经初始化过了
      for (int i = 1; i < len; i++) {
          for (int j = 0; j <= target; j++) {
              // 【情况 A】背包容量 j 太小，根本装不下 nums[i]
              // 必须直接继承上一行的结果
              if (j < nums[i]) {
                  dp[i][j] = dp[i - 1][j];
              } 
              // 【情况 B】背包装得下，那就看 "装" 和 "不装" 哪个价值大
              else {
                  dp[i][j] = Math.max(
                      dp[i - 1][j],               // 不装：保持上一行的状态
                      dp[i - 1][j - nums[i]] + nums[i] // 装：腾出空间后 + 当前物品价值
                  );
              }
          }
      }
      
      // 【步骤 4】检查是否装满
      return dp[len - 1][target] == target;
  }
