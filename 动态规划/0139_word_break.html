问题定义

给定一个非空字符串 s 和一个单词字典 wordDict，判断 s 是否可以被空格拆分为一个或多个在字典中出现的单词。

动态规划思路

设 dp[i] 表示字符串 s 的前 i 个字符（s[0:i]）是否可以被拆分。

递推公式

对于每个位置 i，我们检查所有可能的拆分点 j（0 ≤ j < i）：

dp[i] = dp[j] && s.substring(j, i) in wordDict

其中： - dp[j]：前 j 个字符可以被拆分 - s.substring(j, i)：从 j 到 i 的子串 - in wordDict：该子串在字典中

初始化

dp[0] = true：空字符串可以被拆分（作为基础情况）

遍历顺序

外层循环遍历 i（从 1 到 n），内层循环遍历 j（从 0 到 i-1）。 对于每个 i，检查是否存在一个 j 使得 dp[j] 为 true 且 s[j:i] 在字典中。

Java 代码实现

public boolean wordBreak(String s, List wordDict) {
    int n = s.length();
    boolean[] dp = new boolean[n + 1];
    dp[0] = true;  // 初始化：空字符串可以被拆分
    
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j < i; j++) {
            // 递推公式：dp[i] = dp[j] && s.substring(j, i) in wordDict
            if (dp[j] && wordDict.contains(s.substring(j, i))) {
                dp[i] = true;
                break;  // 只要找到一个匹配即可
            }
        }
    }
    return dp[n];
}
