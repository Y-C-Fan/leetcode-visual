🎯 三数之和 (3Sum)

LeetCode 15 | 双指针解法可视化讲解

题目描述

给你一个整数数组 nums，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足 i != j、i != k 且 j != k，同时还满足 nums[i] + nums[j] + nums[k] == 0。

请你返回所有不重复的三元组。

核心思路

  • 1
    排序数组
    首先对数组进行排序，这是双指针法的前提。排序后可以方便去重和利用单调性移动指针。
  • 2
    固定一个数，双指针找另外两个
    遍历数组，固定第一个数 nums[i]，然后用左右指针 left 和 right 在后面的区间寻找两数之和等于 -nums[i]。
  • 3
    根据三数之和移动指针
    如果和 > 0，右指针左移；如果和 < 0，左指针右移；如果 == 0，找到一个答案。
  • 4
    去重处理
    找到答案后，跳过重复的元素，避免重复的三元组。

Java 代码实现

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        int n = nums.length;
        
        // 1. 排序
        Arrays.sort(nums);
        
        // 2. 遍历固定第一个数
        for (int i = 0; i < n - 2; i++) {
            // 剪枝：如果最小的数都大于0，不可能有解
            if (nums[i] > 0) break;
            
            // 去重：跳过相同的第一个数
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            
            // 3. 双指针寻找另外两个数
            int left = i + 1;
            int right = n - 1;
            
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                
                if (sum == 0) {
                    // 找到一个答案
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    
                    // 去重：跳过相同的左指针元素
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    // 去重：跳过相同的右指针元素
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    
                    // 移动指针继续寻找
                    left++;
                    right--;
                } else if (sum < 0) {
                    // 总和太小，左指针右移
                    left++;
                } else {
                    // 总和太大，右指针左移
                    right--;
                }
            }
        }
        
        return result;
    }
}

复杂度分析

时间复杂度

O(n²)

排序 O(n log n)
双指针遍历 O(n²)

空间复杂度

O(log n)

排序的栈空间
不考虑输出数组

易错点提醒

  • ⚠️
    去重时机
    外层循环去重要在处理完当前元素之后判断；内层循环去重要在找到答案后进行。
  • ⚠️
    边界条件
    注意 i < n - 2 而不是 i < n，因为至少需要3个数。
  • ⚠️
    去重后还要移动指针
    找到答案后去重完，还要执行 left++ 和 right--，否则会死循环。
