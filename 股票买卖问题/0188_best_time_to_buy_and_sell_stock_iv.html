问题定义

给定一个整数数组 prices 和一个整数 k，prices 的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。 你最多可以完成 k 笔交易，设计一个算法来计算你所能获取的最大利润。 注意：你不能同时参与多笔交易（你必须在再次买入前卖出掉之前的股票）。

动态规划思路

我们需要维护 2k 个状态：
- buy[i]：第 i 次买入后的最大利润（负数，表示成本）
- sell[i]：第 i 次卖出后的最大利润
其中 i 从 1 到 k。

递推公式

for i in [1, k]:
  buy[i] = max(buy[i], sell[i-1] - price)
  sell[i] = max(sell[i], buy[i] + price)

初始化

buy[i] = -infinity（初始时不可能持有股票）
sell[i] = 0（初始时没有卖出过的利润）

Java 代码实现

public int maxProfit(int k, int[] prices) {
    int n = prices.length;
    int[] buy = new int[k + 1];
    int[] sell = new int[k + 1];
    Arrays.fill(buy, Integer.MIN_VALUE);
    
    for (int price : prices) {
        for (int i = 1; i <= k; i++) {
            buy[i] = Math.max(buy[i], sell[i - 1] - price);  // 第 i 次买入
            sell[i] = Math.max(sell[i], buy[i] + price);  // 第 i 次卖出
        }
    }
    return sell[k];  // 最终答案
}
