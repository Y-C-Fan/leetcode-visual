问题定义

给定一个数组 prices，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。 你最多可以完成两笔交易，设计一个算法来计算你所能获取的最大利润。 注意：你不能同时参与多笔交易（你必须在再次买入前卖出掉之前的股票）。

动态规划思路

我们需要维护四个状态：
- buy1：第一次买入后的最大利润（负数，表示成本）
- sell1：第一次卖出后的最大利润
- buy2：第二次买入后的最大利润
- sell2：第二次卖出后的最大利润（最终答案）

递推公式

buy1 = max(buy1, -price)
sell1 = max(sell1, buy1 + price)
buy2 = max(buy2, sell1 - price)
sell2 = max(sell2, buy2 + price)

初始化

buy1 = buy2 = -infinity（初始时不可能持有股票）
sell1 = sell2 = 0（初始时没有卖出过的利润）

Java 代码实现

public int maxProfit(int[] prices) {
    int buy1 = Integer.MIN_VALUE, sell1 = 0;
    int buy2 = Integer.MIN_VALUE, sell2 = 0;
    
    for (int price : prices) {
        // 第一次交易
        buy1 = Math.max(buy1, -price);  // 第一次买入
        sell1 = Math.max(sell1, buy1 + price);  // 第一次卖出
        
        // 第二次交易
        buy2 = Math.max(buy2, sell1 - price);  // 第二次买入
        sell2 = Math.max(sell2, buy2 + price);  // 第二次卖出
    }
    return sell2;  // 最终答案
}
