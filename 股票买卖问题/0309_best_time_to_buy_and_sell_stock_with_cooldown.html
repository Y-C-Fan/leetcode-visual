问题定义

给定一个整数数组 prices，其中 prices[i] 表示某支股票第 i 天的价格。 设计一个算法计算出最大利润。在满足以下约束条件下，你可以尽可能地完成更多的交易（多次买卖一支股票）：
- 卖出股票后，你无法在第二天买入股票（即冷冻期为 1 天）。
- 你不能同时参与多笔交易（你必须在再次买入前卖出掉之前的股票）。

动态规划思路

我们需要维护三个状态：
- hold：持有股票时的最大利润
- notHold：不持有股票且不在冷冻期时的最大利润
- cooldown：冷冻期时的最大利润

递推公式

hold = max(hold, notHold - price)
notHold = max(notHold, cooldown)
cooldown = hold + price

初始化

hold = -prices[0]（第一天买入股票）
notHold = 0（第一天不持有股票）
cooldown = 0（第一天不可能在冷冻期）

Java 代码实现

public int maxProfit(int[] prices) {
    int hold = -prices[0];  // 持有股票
    int notHold = 0;  // 不持有股票
    int cooldown = 0;  // 冷冻期
    
    for (int i = 1; i < prices.length; i++) {
        int prevHold = hold;
        int prevNotHold = notHold;
        int prevCooldown = cooldown;
        
        hold = Math.max(prevHold, prevNotHold - prices[i]);  // 递推公式
        notHold = Math.max(prevNotHold, prevCooldown);  // 递推公式
        cooldown = prevHold + prices[i];  // 递推公式
    }
    return Math.max(notHold, cooldown);  // 最终答案
}
