公式：dp[i][j] = dp[i-1][j] + (s[i-1] == t[j-1] ? dp[i-1][j-1] : 0)

问题定义

给定两个字符串 s 和 t，返回 s 中 t 出现的次数。 注意：子序列是指不改变字符的相对顺序，从原字符串中删除一些字符（也可以不删除）后形成的新字符串。

动态规划思路

设 dp[i][j] 表示 s 的前 i 个字符中 t 的前 j 个字符出现的次数。 我们需要考虑 s[i-1] 是否等于 t[j-1]。

递推公式

对于 dp[i][j]：

if s[i-1] == t[j-1]:
  dp[i][j] = dp[i-1][j] + dp[i-1][j-1]
else:
  dp[i][j] = dp[i-1][j]

边界条件： - dp[i][0] = 1：空字符串 t 是任何字符串 s 的子序列 - dp[0][j] = 0（j > 0）：空字符串 s 不能包含非空字符串 t

Java 代码实现

public int numDistinct(String s, String t) {
    int m = s.length(), n = t.length();
    int[][] dp = new int[m + 1][n + 1];
    
    // 初始化第一列：空字符串 t 是任何字符串的子序列
    for (int i = 0; i <= m; i++) {
        dp[i][0] = 1;
    }
    
    // 填充 DP 表格
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s.charAt(i - 1) == t.charAt(j - 1)) {
                // 字符匹配：可以选择使用或不使用 s[i-1]
                dp[i][j] = dp[i - 1][j] + dp[i - 1][j - 1];  // 递推公式
            } else {
                // 字符不匹配：只能不使用 s[i-1]
                dp[i][j] = dp[i - 1][j];
            }
        }
    }
    return dp[m][n];
}
