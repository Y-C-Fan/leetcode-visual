最长递增子序列：动态规划可视化

LeetCode 300 | 示例：nums = [10, 9, 2, 5, 3, 7, 101, 18]

Step 0 i: - j: -
当前计算 dp[i] 比较 nums[j] < nums[i]
dp[i] = max(dp[j] + 1) for all j < i and nums[j] < nums[i]

操作日志

递推公式：dp[i] = max(dp[j] + 1) for all j < i and nums[j] < nums[i]

问题理解

给你一个整数数组 nums ，找到其中最长严格递增子序列的长度。
子序列是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。
例如，[3,6,2,7] 是数组 [0,3,1,6,2,2,7] 的子序列。

递推公式推导

设 dp[i] 表示以 nums[i] 结尾的最长递增子序列的长度。
对于每个位置 i，我们需要遍历所有 j < i：

- 如果 nums[j] < nums[i]，说明 nums[i] 可以接在 nums[j] 后面
- 此时以 nums[i] 结尾的子序列长度可以是 dp[j] + 1
- 我们需要找到所有满足条件的 j 中 dp[j] + 1 的最大值
因此：dp[i] = max(dp[j] + 1) for all j < i and nums[j] < nums[i]

初始化

dp[i] = 1（每个元素本身就是一个长度为 1 的子序列）

Java 代码实现（代码随想录）

public int lengthOfLIS(int[] nums) { if (nums.length == 0) return 0; int[] dp = new int[nums.length]; int result = 1; // 初始化：每个元素至少构成长度为1的子序列 for (int i = 0; i < nums.length; i++) { dp[i] = 1; } for (int i = 1; i < nums.length; i++) { for (int j = 0; j < i; j++) { if (nums[j] < nums[i]) { dp[i] = Math.max(dp[i], dp[j] + 1); // 递推公式 } } result = Math.max(result, dp[i]); // 更新最大值 } return result; }

本例结果

nums = [10, 9, 2, 5, 3, 7, 101, 18]
最长递增子序列长度为 4：[2, 3, 7, 101] 或 [2, 3, 7, 18] 或 [2, 5, 7, 101] 等
