零钱兑换：递推公式与遍历顺序可视化

示例：amount = 11，coins = [1, 2, 5]

Step 0 coin: - j: -
当前更新 dp[j] 来源 dp[j-coin]
dp[j] = min(dp[j], dp[j - coin] + 1)

硬币面值

DP 数组

操作日志

公式：dp[j] = min(dp[j], dp[j - coin] + 1)

问题定义

给定不同面额的硬币 coins 和一个总金额 amount，计算可以凑成总金额所需的最少硬币个数。 如果没有任何一种硬币组合能组成总金额，返回 -1。

动态规划思路

设 dp[j] 表示凑成金额 j 所需的最少硬币个数。

递推公式

对于每个硬币面值 coin，对于每个金额 j（从 coin 到 amount）：

dp[j] = min(dp[j], dp[j - coin] + 1)

其中： - dp[j]：不使用当前硬币时的最少硬币数 - dp[j - coin] + 1：使用当前硬币时的最少硬币数（凑成 j - coin 的硬币数 + 1）

初始化

dp[0] = 0：凑成金额 0 需要 0 个硬币
dp[j] = ∞（j > 0）：初始时设为无穷大，表示无法凑成

遍历顺序

外层循环遍历硬币，内层循环金额递增。 这样可以确保每种硬币只被使用一次（完全背包问题）。

Java 代码实现

public int coinChange(int[] coins, int amount) {
    int max = amount + 1;
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, max);  // 初始化为无穷大
    dp[0] = 0;  // 凑成金额 0 需要 0 个硬币
    
    for (int coin : coins) {
        for (int j = coin; j <= amount; j++) {
            // 递推公式：取最小值
            dp[j] = Math.min(dp[j], dp[j - coin] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}

amount = 11，coins = [1, 2, 5]
