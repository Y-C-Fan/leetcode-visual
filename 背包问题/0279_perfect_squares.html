DP 数组

操作日志

公式：dp[j] = min(dp[j], dp[j - square] + 1)

问题定义

给定正整数 n，找到若干个完全平方数（比如 1, 4, 9, 16, ...）使得它们的和等于 n。 你需要让组成和的完全平方数的个数最少。

动态规划思路

设 dp[j] 表示组成数字 j 所需的最少完全平方数个数。

递推公式

对于每个完全平方数 square，对于每个数字 j（从 square 到 n）：

dp[j] = min(dp[j], dp[j - square] + 1)

其中： - dp[j]：不使用当前完全平方数时的最少个数 - dp[j - square] + 1：使用当前完全平方数时的最少个数（组成 j - square 的个数 + 1）

初始化

dp[0] = 0：组成数字 0 需要 0 个完全平方数
dp[j] = ∞（j > 0）：初始时设为无穷大，表示无法组成

遍历顺序

外层循环遍历完全平方数，内层循环数字递增。 这样可以确保每种完全平方数可以被使用多次（完全背包问题）。

Java 代码实现

public int numSquares(int n) {
    int max = n + 1;
    int[] dp = new int[n + 1];
    Arrays.fill(dp, max);  // 初始化为无穷大
    dp[0] = 0;  // 组成数字 0 需要 0 个完全平方数
    
    for (int i = 1; i * i <= n; i++) {
        int square = i * i;
        for (int j = square; j <= n; j++) {
            // 递推公式：取最小值
            dp[j] = Math.min(dp[j], dp[j - square] + 1);
        }
    }
    return dp[n];
}

n = 12，可用完全平方数：[1, 4, 9]
