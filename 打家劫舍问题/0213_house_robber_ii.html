打家劫舍 II：环形房屋递推可视化

示例：nums = [2, 3, 2, 1, 4]

情况1：不打劫首尾
情况2：不打劫尾首
最终结果
Step 0 i: - max: -
当前计算 dp[i] 来源 dp[i-2] 和 dp[i-1] 房屋金额
dp[i] = max(dp[i-2] + nums[i], dp[i-1])

操作日志

公式：dp[i] = max(dp[i-2] + nums[i], dp[i-1])

环形房屋的特殊性

与普通打家劫舍不同，环形房屋中首尾相连，不能同时打劫第一间和最后一间房屋。 因此需要分两种情况讨论：

两种情况分析

情况1：不考虑最后一间房屋
在 nums[0:n-1] 范围内求最大金额，即打劫第一间但不打劫最后一间。

情况2：不考虑第一间房屋
在 nums[1:n] 范围内求最大金额，即不打劫第一间但可以打劫最后一间。

递推公式

对于线性情况（情况1或情况2），使用与 House Robber I 相同的递推公式：

dp[i] = max(dp[i-2] + nums[i], dp[i-1])

其中： - dp[i-2] + nums[i]：打劫当前房屋，不能打劫前一间，只能打劫前两间 - dp[i-1]：不打劫当前房屋，继承前一间房屋的最大金额

最终结果

取两种情况的最大值：max(情况1结果, 情况2结果)

Java 代码实现

// 主函数：分两种情况处理
public int rob(int[] nums) {
    if (nums == null || nums.length == 0) return 0;
    if (nums.length == 1) return nums[0];
    
    // 情况1：不考虑最后一间
    int result1 = robLinear(nums, 0, nums.length - 2);
    // 情况2：不考虑第一间
    int result2 = robLinear(nums, 1, nums.length - 1);
    
    return Math.max(result1, result2);
}

// 线性打家劫舍（House Robber I）
private int robLinear(int[] nums, int start, int end) {
    int prev2 = 0;  // dp[i-2]
    int prev1 = 0;  // dp[i-1]
    
    for (int i = start; i <= end; i++) {
        int curr = Math.max(prev2 + nums[i], prev1);  // 递推公式
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
